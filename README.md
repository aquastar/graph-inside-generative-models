# Is There a Graph Inside Generative Models?

Evidence from Language and Music. RIT Computer Science internal talk, built with reveal.js.

Play online: https://aquastar.github.io/graph-inside-generative-models/

Keys: Space or arrows to advance, Esc or O for the slide overview, S for speaker notes.

Status labels on result slides: Published, Under review, In progress, Open question.

Structure: Vision, Part 1 Depth: language, Part 2 Time: music (including music and the brain), Part 3 Beyond, Close. The language slides are condensed from https://github.com/aquastar/neural-networks-to-networks. Build with python3 src/build.py.
